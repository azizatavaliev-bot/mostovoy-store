# МОСТОВОЙ — каталог смартфонов (обмен · рассрочка)

Бело-красный минималистичный каталог Apple/Samsung для магазина «Мостовой» (Бишкек).
Витрина: каталог, страница товара, калькулятор рассрочки со ставкой, трейд-ин, кнопки-заявки в WhatsApp/Telegram.

## Стек
Чистый HTML + CSS + JS (без сборки). Шрифт Montserrat. Запуск — любой статик-сервер.

## Запуск локально
```bash
python3 -m http.server 5190
# открыть http://localhost:5190
```

## Структура
| Файл | Назначение |
|------|-----------|
| `index.html` | Главная: hero, статы, каталог с фильтрами, «Почему мы лучшие», обмен, доступ |
| `product.html` | Страница товара (`product.html?id=<id>`): фото, ТТХ, трейд-ин + рассрочка, похожие |
| `data.js` | Каталог `PHONES` (18 моделей) + контакты магазина `STORE` |
| `render.js` | SVG-рендеры телефонов, кастомные дропдауны, шапка, формула рассрочки, `mediaHTML` |
| `script.js` | Логика главной: фильтры (бренд/поиск/сортировка), калькуляторы, анимации |
| `product.js` | Логика страницы товара: цвет/память, трейд-ин калькулятор |
| `styles.css` | Все стили (премиум-минимализм, бело-красный, адаптив) |
| `photos.js` | Автогенерация ссылок на фото (Samsung из Icecat) — см. ниже |
| `fetch-photos.js` | Node-скрипт: тянет фото из Open Icecat → пишет `photos.js` |
| `images/` | Локальные фото товара (имя = `<id>.jpg`), необязательно |

## Фото товаров
- **Samsung и др. бренды** — тянутся автоматически из **Open Icecat** по логину (без токена):
  ```bash
  ICECAT_USER=<icecat-логин> node fetch-photos.js
  ```
  Обновляет `photos.js`. Приоритет источника фото: `p.img` → `photos.js` → `images/<id>.jpg` → SVG-рендер.
- **Apple заблокирован в Icecat** (brand restrictions) → по iPhone используются SVG-рендеры или фото от поставщика (положить в `images/`, напр. `16-pro.jpg`).

## Контакты для кнопок «Купить/Доставка»
В `data.js`, объект `STORE`: `wa` — номер WhatsApp (межд. формат без `+`), `tg` — username Telegram.

## Калькуляторы
- Рассрочка: аннуитет (`installment()` в `render.js`). Ставка 0/12/18% → платёж, переплата, итого.
- Трейд-ин: оценка старого телефона по состоянию → вычет из цены → рассрочка на остаток.

## Дорожная карта (следующие этапы)
1. Бэкенд + админка (товары/цены в БД, сайт читает живой `catalog.json` / API).
2. Telegram-бот загрузки цен → подтверждение изменений кнопками → обновление сайта.
3. Sales-боты Telegram/WhatsApp/Instagram с актуальными ценами.
4. Импорт из 1С.

Подробнее об интеграции с Telegram — в `TELEGRAM-SYNC.md`.
