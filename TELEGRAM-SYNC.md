# МОСТОВОЙ — синхронизация с Telegram (архитектура)

Цель: **цены и фото на сайте обновляются сами**, когда магазин обновляет их в Telegram.
Владелец ничего не программирует — просто ведёт Telegram как обычно.

## Как это работает (алгоритм)

```
[Telegram-канал / бот-загрузчик]   ← магазин выкладывает: фото + "iPhone 15 128 — 79990"
            │
            ▼
[Бот-парсер (Node на Railway)]     ← читает посты, вытаскивает: модель, цена, фото
            │  сохраняет
            ▼
[catalog.json + фото по URL]       ← готовые данные (или API /api/catalog)
            │  сайт запрашивает при загрузке
            ▼
[Сайт «Мостовой»]                  ← рендерит каталог из свежих данных
```

## Компоненты

1. **Бот-загрузчик** (отдельный Telegram-бот магазина)
   - Магазин шлёт боту фото телефона + подпись с ценой и памятью.
   - Или бот читает существующий канал с прайсом (если формат стабильный).

2. **Парсер (backend, Node/Express на Railway)**
   - Разбирает подпись → `{ бренд, модель, память, цена }`.
   - Берёт фото из Telegram (`file_id` → постоянный URL) и сохраняет.
   - Пишет `catalog.json` (или отдаёт `/api/catalog`).

3. **Сайт** (то, что уже готово)
   - Сейчас данные в `data.js` (константа `PHONES`).
   - Следующий шаг: сайт грузит `catalog.json` вместо `data.js` → данные живые.
   - Поле `img` у товара = URL фото из Telegram → **фото не скачиваем вручную**.

## Про фото — важно (легально)
Фото из **вашего** Telegram — это **ваш контент**, его использовать можно.
Фото с чужих сайтов (Apple, конкуренты) — нельзя (копирайт).
→ Тянем только ваши фото из вашего Telegram.

## Кнопки-заявки (уже на сайте)
Купить · Заказать доставку → ведут в WhatsApp/Telegram с готовым текстом (модель + цена).
Настройка: `STORE` в `data.js` (`wa` — номер WhatsApp, `tg` — username).
